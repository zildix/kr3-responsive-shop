## Контрольная работа №3
**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

### Адаптивные решения
- добавлен файл `css/responsive.css`;
- применён подход **Mobile First** (в `style.css` описана мобильная версия, в `responsive.css` — десктопная);
- добавлены медиазапросы (`min-width`);
- адаптирована навигация (реализовано мобильное бургер-меню);
- адаптирован hero-блок (текст не сжимается, перестраивается раскладка);
- адаптирована сетка карточек (Grid перестраивается от 1 до 4 колонок);
- адаптированы изображения: применены свойства `max-width: 100%`;
- реализованы **responsive images**: на странице товара добавлены атрибуты `srcset` и `sizes`;
- адаптирована форма заявки (перестроение колонок, фикс вылета длинного `select` через обрезку текста `text-overflow: ellipsis`);
- адаптирована таблица характеристик (добавлен `.table-wrapper` с горизонтальным `overflow-x: auto` для защиты от поломки экрана).

### Проверенные ширины
- 360px (Мобильный)
- 430px (Мобильный крупный)
- 768px (Планшет)
- 1024px (Небольшой desktop)
- 1440px (Широкий desktop)

### Доступность (A11y)
- проверена семантическая структура страниц (иерархия заголовков, теги `<nav>`, `<main>`, `<article>`);
- добавлена скрытая ссылка `skip-link` для быстрого перехода к основному содержимому с клавиатуры;
- проверена навигация с клавиатуры (через клавишу `Tab`);
- добавлен видимый фокус `:focus-visible` для всех интерактивных элементов;
- проверены атрибуты `alt` у изображений;
- декоративные элементы (иконки, эмодзи) скрыты от скринридеров через `aria-hidden="true"`;
- активные ссылки меню помечены атрибутом `aria-current="page"`;
- проверены формы (жесткая связь `label for` и `input id`);
- модальное окно реализовано через семантичный тег `<dialog>` с правильным позиционированием.

### Lighthouse
Выполнен аудит доступности (Accessibility) через Google Lighthouse.
Проверены страницы:
- `index.html`
- `catalog.html`
- `order.html`

Исправлены проблемы контрастности и недостающих подписей. Отчёт сохранён в папке `lighthouse/`.

## Контрольная работа №4 (Начало работы)
**Тема:** «JavaScript: интерактивность, DOM, события, формы и валидация».

### Реализованный JS-функционал (Vanilla JS)
- весь код обернут в `DOMContentLoaded` для безопасного выполнения;
- **Мобильное меню:** скрипт переключает видимость навигации по клику на бургер и управляет атрибутом `aria-expanded`;
- **Кнопка "Наверх":** отслеживание `window.scrollY` для плавного появления кнопки и скролла наверх;
- **Модальное окно:** 
  - открытие/закрытие через нативные методы `<dialog>` (`showModal()`, `close()`);
  - блокировка прокрутки основного фона (`body overflow: hidden`) при открытом окне;
  - закрытие по клику на крестик или вне области окна (на затемненный backdrop);
  - передача названия товара в скрытый `input` формы при клике на "Заказать" в карточке товара;
- **Валидация формы:** использование встроенного HTML5 Validation API с визуальной подсветкой ошибок через `aria-invalid`.
